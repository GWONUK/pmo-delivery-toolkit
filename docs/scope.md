# 역할과 검증 범위

| 구분 | 수행 범위 | 이 저장소에서 볼 수 있는 근거 |
|---|---|---|
| 개인이 맡은 구현 | 아키텍처 및 배포 경로 설계, Ansible 자동화, Python 배포 프로그램과 구성 파일 수집 및 해시 대조 도구 | 선정된 코드와 해당 모의시험 |
| 팀 협업 | 팀원이 작성하고 적용한 Terraform과 클라우드 통합 시험 기록을 설계 조건에 맞춰 검토 | Notion 설명 및 팀 공개 아키텍처 링크 |
| 이번 공개 작업 | 내부 값을 예시로 치환하고 원격 실행 기본 차단을 추가한 뒤 재검증 | 출처 목록, 공개 파일 해시와 재검증 결과 |

원본 공동 저장소에는 협업과 AI 지원을 통한 수정 이력이 있습니다. 이 저장소는 담당 범위의 구현물을 공개하기 위한 발췌이며, 모든 원본 코드를 혼자 작성했다고 주장하는 자료가 아닙니다.

프로젝트 당시 Ansible 서버 적용과 재적용, 이미지 검사, 팀 통합 시험은 각각의 조건을 가진 별도 기록입니다. 이번 로컬 모의시험으로 당시 실제 환경 시험을 다시 수행했다고 표시하지 않습니다. 개인 배포 프로그램을 통한 실제 클라우드 자동 배포도 이번 검증 범위에 포함되지 않습니다.

팀원이 실제 환경에서 수행한 기능 시험 11건과 별도 경계값 시험 14건은 이 저장소의 모의시험 건수에 합산하지 않습니다. 실제 환경의 상세 조건은 연결한 포트폴리오와 팀 자료에서 확인할 수 있습니다.
