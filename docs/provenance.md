검사기 연결 코드에는 공개된 `321Team/fds-msa`의 검사기 경로와 고정 해시도 참조되어 있습니다. 해당 검사기 자체나 그 저장소의 실제 배포 구성은 이 저장소에 복사하지 않았습니다.

## 공개를 위해 바꾼 내용

- 내부 주소는 문서용 주소 또는 예시 변수로 바꿨습니다. 원본 인벤토리는 복사하지 않았습니다.
- 개인 이름이 포함된 주석과 내부 작업 식별자는 제거하거나 일반적인 용어로 바꿨습니다.
- Python의 내부 schema 이름은 공개용 이름으로 바꿨습니다. 기존 내부 결과와 동일한 schema로 처리해서는 안 됩니다.
- Ansible 예시 인벤토리와 명시적 원격 실행 허용 조건을 추가했습니다. 허용 조건은 태그 선택과 작업 중간 시작에 대비해 역할 및 작업 블록에도 적용했습니다. SSH 합성 시험은 새 작업 블록에서 검사 태스크를 추출하도록 바꿨습니다. 서버 설정과 검증 조건의 핵심 로직은 보존했습니다.
- 공개 저장소용 안내, 정적 점검과 합성 자료 실행 스크립트를 추가했습니다.

원본 파일과 이번 공개본의 차이, 원본 해시 검증 기록은 소유자의 로컬 보관 경로에 별도로 남겼습니다. 공개 저장소에는 원본 내부 값이 드러나는 diff나 실행 기록을 올리지 않습니다.

원본에서 별도의 라이선스를 확인하지 못했으므로 MIT 등 새 이용허락은 추가하지 않았습니다. 원본 공동 작업의 출처와 권리를 유지합니다.
